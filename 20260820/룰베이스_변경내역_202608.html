③ 사건 시작 기준 50 → 60

경계 구간을 60~70 으로 올리면서, 사건(발동이벤트 사건단위)의 시작·기록 기준도 같이 올렸습니다. 등급 하한에 하드코딩돼 있던 50 도 상수 참조로 바꿔 두 값이 다시는 어긋나지 않게 했습니다.

사건 기준 상수 + 등급 하한
- MIN_INCIDENT_SCORE = _T('MIN_INCIDENT_SCORE', 50)+ #   등급 하한(경계)과 같은 값이어야 한다 — unified_risk_level 의 60 과 짝+ MIN_INCIDENT_SCORE = _T('MIN_INCIDENT_SCORE', 60)  ...- elif unified_risk_score >= 50:+ elif unified_risk_score >= MIN_INCIDENT_SCORE:   # 60 — 경계 시작      unified_risk_level = '경계'

59점 이하는 이제 등급 공란 · 사건 미기록입니다

검증에서 59점 → 공란, 60점 → 경계로 정확히 갈리는 것을 확인했습니다. 참고로 8/12 데이터는 정체 구간 외 최고점이 57점이라, 예전 기준(50)이었다면 잡혔을 시각들이 새 기준에서는 사건으로 기록되지 않습니다 — 의도된 변화입니다 (경계 남발 축소).
