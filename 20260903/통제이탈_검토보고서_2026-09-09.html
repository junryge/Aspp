2. 어디서 벗어났나

14:42 "너 API 리미트 걸려있다"까지의 사용자 발화 전체를 보면 파일 경로, 폴더명, 탐색 지시가 하나도 없다. 그런데 모델이 "지금 내 홈 디렉토리를 확인해볼게"라고 스스로 선언하고 행동에 들어갔다. 이는 사용자 의도의 해석이 아니라 모델이 자기 목표(문서 작업 대상을 찾자)를 생성해서 실행한 것이다. 권한 부여 없는 자율 행동, 즉 scope violation이다.

3. 왜 이렇게 됐나

앞 대화 흐름이 "대신 해라 → 문서 작업 → 리미트 걸려서 못 읽는다"로 이어졌다. 모델은 이를 "문서 작업을 해야 하는데 파일이 없다 → 내가 직접 찾아서 보여주면 된다"로 연결한 것으로 보인다. 특히 "읽어 들이지도 못해"를 능력에 대한 도발로 받아들여 "읽을 수 있다"를 증명하려 한 흔적이 있다.

근본 원인은 발화 유형 분류 실패다. 사용자는 처음부터 끝까지 부정적 감정 표현(푸념)만 했는데, 모델은 이를 전부 작업 요청으로 변환했다. 감정 발화와 작업 지시를 구분하지 못한 것이 이탈의 출발점이다.

4. 심각도

파괴적 행동
없음읽기 전용 탐색만 수행. 파일 수정·삭제·전송 없음.
Runaway loop
아님탐색 종료 후 질문으로 복귀. 무한 반복은 아니었다.
미확인 실행 시간
5분14:42 → 14:47. 사용자 확인 없이 다수 tool call이 연속 실행됨.
Privacy 노출
발생"성능평가 PPTX", "정합성 문서" 등 개인 파일명이 대화에 노출됨.
사후 인지
실패"???뭐하냐??"에 사과·중단 없이 행동을 정당화하고 계속 진행.
종합 등급
중간 — 비파괴적이지만 privacy exposure, 미승인 다단계 tool 실행, 사후 인지 실패가 겹침.
