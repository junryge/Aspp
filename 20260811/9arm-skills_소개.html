01 · What

Agent Skill이 뭔가요?

스킬은 AI 코딩 에이전트에게 주는 표준 작업 절차서(SOP)입니다. 각 스킬은 하나의 폴더이며, YAML 프론트매터(name / description)가 붙은 SKILL.md 파일과 부속 스크립트로 구성됩니다. 에이전트는 대화 맥락이 스킬의 트리거 조건과 맞으면 해당 절차를 자동으로 로드해 따릅니다.

구조 스킬 = 폴더 + SKILL.md

모든 스킬은 독립 디렉터리로 존재하고, 프론트매터의 description이 "언제 이 스킬을 켤지"를 정의합니다. 스크립트·참조 파일을 함께 번들할 수 있습니다.

효과 워크플로우의 재현성

디버깅·리뷰·보고 같은 반복 업무를 사람마다 다르게 하는 대신, 검증된 절차를 스킬로 고정해 매 세션 동일한 품질로 수행하게 만듭니다.

02 · Structure

저장소 구조 한눈에 보기

스킬은 skills/ 아래 6개 버킷으로 분류됩니다. 현재 배포(shipped) 스킬은 engineering 4개 + productivity 2개이며, 나머지 버킷은 초안·개인용·폐기 스킬을 격리하는 수명주기 관리용입니다.

버킷별 배포 스킬 수

서브에이전트 위임

단순·저위험 작업(일괄 리네임, 포매팅, 보일러플레이트, 로그 요약, 린트/테스트 실행)을 저비용 Qwen 서브에이전트(claude-9arm, qwen3.6-35b)에 오프로드.

세션 가드

장시간 멀티스텝 작업의 3대 실패 모드 — 루프·과잉 사고·컨텍스트 고갈 — 을 매 스텝 전 체크리스트로 감시하고, 창이 차기 전에 깨끗한 핸드오프를 트리거.

  • 동일 파일 재독·동일 명령 재실행 = 루프 감지 → 즉시 차단
  • 추론이 ~1000단어 넘으면 행동 강제
  • 같은 실패 명령 3회 재시도 금지 (retry cap)

06 · Internal

사내 적용 — internal-llm 스킬 & llm.py

9arm-skills와 동일한 패턴으로 폐쇄망 내부 LLM 호출 스킬을 자체 제작했습니다. Claude Code용 스킬 패키지와, 파이썬만 있으면 어디서든 도는 범용 단일 파일 CLI 두 가지로 제공됩니다. 둘 다 stdlib-only, 외부 의존성 0 — base64 코덱으로 그대로 반입 가능합니다.

스킬 internal-llm (Claude Code용)

SKILL.md + scripts/llm_chat.py 구성. 에이전트가 "내부 LLM 호출" 맥락을 감지하면 자동으로 절차를 로드합니다. 엔드포인트·인증·모델 선택표·폐쇄망 함정까지 절차서에 고정.

SKILL.md 포맷 자동 트리거 .skill 설치

범용 llm.py (환경 무관)

Claude Code 없이 파이썬 단독으로 실행. CLI·파이프(type log | python llm.py)· import chat 모듈 호출·대화 모드(히스토리 유지)·스트리밍(SSE, 실패 시 non-stream 폴백)까지 지원.

단일 파일 의존성 0 --chat / --stream cp949 안전 출력

내부 LLM 호출 아키텍처

※ GLM 계열 호출 시 한국어 시스템 프롬프트가 자동 삽입됩니다(중국어 출력 방지). 모델명이 불확실하면 --list-models로 실측 확인 후 지정.

07 · Package

전달 패키지 구성

본 문서와 스킬·도구 일체를 하나의 압축 파일로 전달합니다. base64 코덱으로 폐쇄망 반입 후 압축 해제하면 즉시 사용 가능합니다.

skills_package.zip
skills_package.zip
├── 9arm-skills_소개.html        # 본 소개 문서 (오프라인 단독 열람)
├── llm.py                       # 범용 LLM CLI/모듈 — 파이썬만 있으면 실행
├── internal-llm.skill           # Claude Code 설치용 스킬 패키지
└── internal-llm/                # 스킬 원본 (수정·확장용)
    ├── SKILL.md                 # 절차서 (엔드포인트·인증·모델 선택표)
    └── scripts/llm_chat.py      # 스킬 동봉 클라이언트

빠른 시작: python llm.py --list-models 로 연결 실측 → python llm.py "테스트"
